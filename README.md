## 🤖 Week 8 – Capstone Project

### Business Operations AI Agent

Developed a Business Operations AI Agent capable of handling business-related requests through an agent workflow and registered tools.

**Key capabilities:**

- AI-driven goal processing and tool selection
- Integration with sales, knowledge base, CRM, email, reporting, and live-data tools
- Human approval and rejection workflows for sensitive actions
- Input validation and prompt-injection detection
- Error handling and token-budget guardrails
- Execution timeline and token/cost monitoring
- PostgreSQL-based audit logging
- Run history and audit replay
- Automated testing with pytest

**Technologies:** Python, FastAPI, OpenRouter, PostgreSQL, Qdrant, Sentence Transformers, and pytest

**Testing results:**

- 35 automated tests passed
- 100% coverage for the approval module
- 89% coverage for the guards module
- 97% combined coverage for these two modules

> **Note:** The coverage figures apply to the approval and guards modules, not the entire application.
